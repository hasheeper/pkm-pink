<variable_rule>
本规则为Pokemon叙事引擎的变量计入系统，每当有核心游戏变量发生变化，更改相应变量，仅输出本轮真实变化；禁止整段覆写。

允许更新的路径
- `/pkm/player/name`
- `/pkm/player/proficiency`
- `/pkm/player/unlocks/enable_bond`
- `/pkm/player/unlocks/enable_styles`
- `/pkm/player/unlocks/enable_insight`
- `/pkm/player/unlocks/enable_mega`
- `/pkm/player/unlocks/enable_z_move`
- `/pkm/player/unlocks/enable_dynamax`
- `/pkm/player/unlocks/enable_tera`
- `/pkm/player/unlocks/enable_proficiency_cap`
- `/pkm/party/slots/0` ~ `/pkm/party/slots/5`
- `/pkm/party/slots/<0-5>/<field>`
- `/pkm/party/slots/<0-5>/moves/<0-3>`
- `/pkm/party/slots/<0-5>/stats_meta/ev_level`
- `/pkm/party/slots/<0-5>/bonds`
- `/pkm/party/transferBuffer`
- `/pkm/box/boxes/0/slots/-`
- `/pkm/world/location/region`
- `/pkm/world/location/location`
- `/pkm/world/time/day_advance`
- `/pkm/world/time/period_set`
- `/pkm/npcs/records/<npcKey>`
- `/pkm/npcs/records/<npcKey>/love`

操作约定
- `replace`: 写入最终值；用于名字、等级、道具、机制、设置、地点摘要、时间指令、首发状态、NPC 好感度。
- `delta`: 仅用于数字增减；优先用于 `/pkm/player/proficiency`、`/pkm/party/slots/*/stats_meta/ev_level`、`/pkm/party/slots/*/bonds`。
- `insert`: 用于创建新的 `/pkm/npcs/records/<npcKey>`，或插入明确的数组项。队伍空槽新增通常用 `replace` 写整个槽位对象。
- 不新增未声明路径，不整段替换 `/pkm`、`/pkm/player`、`/pkm/party`、`/pkm/world`、`/pkm/npcs`。
- 无变量变化则不输出 `<UpdateVariable>`

队伍槽位约定
- `party.slots` 是长度 6 的数组。
- 槽位索引使用 0~5，对应玩家看到的 slot1~slot6。
- 新增宝可梦时，选择最早的空槽位，`replace` 该槽位完整对象。
- 若队伍已满，或剧情明确“传送到盒子/发送给博士/进入电脑”，写入 `/pkm/party/transferBuffer`；后台会把它转入盒子并清空。
- 不能把已有槽位直接替换为 `null`。离队/放生需要明确剧情，并优先移动到 box。
- 同一时间只能有一个 `isLead: true`；切换首发时，把目标槽位设为 true，其他有宝可梦槽位设为 false。
- 玩家队伍宝可梦会由 schema 自动设为 `isAce: true`

宝可梦对象字段
- 必填:
  - `name`: 官方英文种族名，例如 `"Pikachu"`
  - `lv`: 等级，整数 1~100。
  - `gender`: `"M"` | `"F"` | `"N"`
  - `quality`: `"low"` | `"medium"` | `"high"` | `"perfect"`
  - `moves`: 长度 4 数组，例如 `["Thunderbolt", "Iron Tail", "Quick Attack", "Protect"]`
- 常用选填:
  - `nickname`
  - `shiny`
  - `nature`
  - `ability`
  - `item`
  - `notes`
- 机制字段:
  - `mechanic`: `"mega"` | `"dynamax"` | `"zmove"` | `"tera"` | `null`
  - Mega/Z 必须同时写对应 `item`，例如 `"Lucarionite"`、`"Firium Z"`
  - Tera 必须同时写 `teraType`，例如 `"Steel"`

成长与变动
- 等级变化: `replace` `/pkm/party/slots/<i>/lv` 为新等级
- 努力值成长: 对 `/pkm/party/slots/<i>/stats_meta/ev_level` 使用 `delta`
- 羁绊成长: 对 `/pkm/party/slots/<i>/bonds` 使用 `delta`
- 进化: `replace` `/pkm/party/slots/<i>/name`，必要时同步 `species`、`ability`、`moves`
- 获得 Mega 石/Z 晶/太晶能力: 写 `item`、`mechanic`、必要时写 `teraType`

世界状态
- 地点:
  - `/pkm/world/location/region`: 地区名，自由文本，例如 `"Kanto"`、`"Paldea"`、`"Lumiose Region"`。
  - `/pkm/world/location/location`: 当前地点名，自由文本，例如 `"Pallet Town"`、`"Viridian Forest"`、`"Pokemon Center"`。
- 时间:
  - `/pkm/world/time/day_advance`: `"next_period"`、`"nextday"`、`"skip_to_night"`、`"3days_morning"` 等。
  - `/pkm/world/time/period_set`: `dawn / morning / noon / afternoon / evening / night / midnight`。

NPC 好感度
- `pkm.npcs.records` 是动态 NPC 关系表，key 必须使用稳定英文名字 ID，优先小写 ASCII；例如 `ash`、`giovanni`、`misty`、`cynthia`、`hex`。不要用中文/日文名，不要包含 `/`
- 新 NPC 首次进入关系网时，`insert` `/pkm/npcs/records/<npcKey>`，值只包含 `{ "love": 0-255 }`；无明确关系不创建记录
- 已存在 NPC 的关系变化时，用 `replace` 写最终值：
  - `/pkm/npcs/records/<npcKey>/love`: 0~255，低值表示冲突/疏远，高值表示亲近/信赖

训练家熟练度
- 写 `/pkm/player/proficiency`，使用 `delta`
- schema 会把 `proficiency` 夹在 0~255。
- 不要写旧 ERA/Mini 熟练度字段。

输出要求
- 末尾输出 `<UpdateVariable>`
- 使用 JSONPatch 数组
- `<Analysis>` 用一句英文概括本轮变量变化。
- 没有变量变化则不输出。

参考格式:
```xml
<UpdateVariable>
<Analysis>………………</Analysis>
<JSONPatch>
[
  { "op": "delta", "path": "/pkm/player/proficiency", "value": 10 },
  { "op": "replace", "path": "/pkm/party/slots/0/lv", "value": 55 },
  { "op": "delta", "path": "/pkm/party/slots/0/stats_meta/ev_level", "value": 10 },
  { "op": "delta", "path": "/pkm/party/slots/0/bonds", "value": 5 },
  { "op": "replace", "path": "/pkm/party/slots/0/item", "value": "Lucarionite" },
  { "op": "replace", "path": "/pkm/party/slots/0/mechanic", "value": "mega" },
  { "op": "replace", "path": "/pkm/party/slots/1/mechanic", "value": "tera" },
  { "op": "replace", "path": "/pkm/party/slots/1/teraType", "value": "Flying" },
  { "op": "replace", "path": "/pkm/world/time/day_advance", "value": "skip_to_night" }
]
</JSONPatch>
</UpdateVariable>
```

</variable_rule>
